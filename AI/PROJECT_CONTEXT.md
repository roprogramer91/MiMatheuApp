# MiMatheu — Project Context

## Qué es MiMatheu

MiMatheu es una aplicación pensada para la comunidad de Matheu, partido de Escobar, Buenos Aires, Argentina.

No es una app genérica para múltiples ciudades. Su alcance principal es Matheu y sus barrios/zonas.

## Objetivo

Crear una plataforma local útil, simple y confiable para resolver necesidades cotidianas de vecinos de Matheu.

## Secciones principales previstas

- Farmacias de turno.
- Mascotas perdidas y encontradas.
- Servicios locales.
- Comercios.
- Novedades.
- Eventos.
- Información comunitaria.

## Usuario objetivo

Vecinos de Matheu que necesitan información rápida, clara y local.

La app debe ser fácil de usar para personas con distintos niveles de familiaridad tecnológica.

## Principios de producto

- Local primero.
- Información clara antes que decoración excesiva.
- Pocos pasos para acciones importantes.
- Diseño moderno pero cercano.
- Confianza comunitaria.
- Lenguaje simple y directo.

## Identidad visual buscada

MiMatheu debe sentirse como un producto moderno y confiable, con estética limpia, aireada y premium.

Inspiración visual:

- Stripe.
- Linear.
- Airbnb.
- Vercel.
- Apple.

Pero adaptado a una app comunitaria local: amable, clara y práctica.

## Regla importante de alcance

Cuando una pantalla necesite filtros geográficos, usar barrios o zonas de Matheu, no ciudades.

Ejemplo correcto:

- Todos los barrios.
- Centro.
- La Escalada.
- San Enrique.
- Parque Matheu.

Ejemplo incorrecto:

- Todas las ciudades.
