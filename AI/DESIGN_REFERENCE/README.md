# MiMatheu Design System v1

## Filosofía

Minimalista.

Mucho espacio en blanco.

Información antes que botones.

Cards grandes.

Colores vivos solamente para acciones importantes.

La Home es un resumen inteligente, no un menú.

## Paleta

Fucsia principal

Fondos blancos

Gris muy claro

Texto negro
